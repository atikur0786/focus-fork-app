# FocusFork Product Context

## Register
product

## Product Purpose
FocusFork is a guided open-source contribution companion. It helps developers go from GitHub issue discovery to a merged pull request with AI guidance, human approval gates, and their preferred local editor.

## Users
- Individual developers contributing to OSS for the first time or regularly
- Maintainers who want a repeatable issue-to-PR workflow
- Students and career builders assembling a public contribution history

## Brand Voice
- Calm, precise, and trustworthy
- Technical without jargon overload
- Action-first: show the next step, not generic chat

## Anti-references
- Neon crypto dashboards
- Purple-gradient SaaS hero templates
- Chat-first AI tools with no workflow structure
- Embedded Monaco editors pretending to be IDEs

## Strategic Principles
1. Desktop app is the workflow control plane; VS Code/Cursor is the editor
2. Every destructive action passes through human approval
3. Backend handles auth sync, AI proxy, quotas, and contribution history
4. Landing page sells exactly what the desktop app can do today
